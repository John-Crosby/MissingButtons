MissingButtons by John Crosby

Nine free utility plug-ins: the buttons your mixer is missing.
No user interface, no parameters, no latency -- insert one and it does its job.

  Flip         polarity (phase) inverter, every channel
  FlipRight    inverts the polarity of the right channel;
               mono in -> L = x, R = -x
  Left         left channel on both outputs
  Right        right channel on both outputs
  Mono         stereo to mono, (L + R) / 2 on both outputs
  MidSide      mid/side encoder and decoder (* 0.707)
  Side         side signal only, (L - R) / 2
  Swap         swaps left and right
  SideChainer  outputs the sidechain input in place of the main input

Installed for every user of this computer:
  VST3   C:\Program Files\Common Files\VST3
  CLAP   C:\Program Files\Common Files\CLAP
  AAX    C:\Program Files\Common Files\Avid\Audio\Plug-Ins (if included)

64-bit Windows only.
